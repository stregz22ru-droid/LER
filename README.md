# LER — Language of Engineering Reasoning

## ⚠️ Статус проекта: Фундаментальное исследование

**Текущий этап:** Этап 0–1 (Организационный контур и Научная рамка).

На данном этапе проект **НЕ** создает:
* формальный язык;
* DSL (Domain-Specific Language);
* онтологию;
* нотацию или синтаксис;
* программную систему или IDE.

**Цель текущего этапа:** 
Исследовать сам вопрос о том, существует ли феномен инженерного рассуждения (путь принятия решений, отвергнутые варианты, скрытые ограничения) как научно описываемая сущность, и допускает ли он принципиальную возможность формализации без потери существенной информации.

Проект придерживается строгой эпистемической дисциплины. Отрицательный результат (доказательство невозможности описания феномена или некорректности самой постановки вопроса) считается полностью валидным и успешным завершением исследовательской программы.

## Структура репозитория (Текущая)

    LER/
    ├── docs/
    │   ├── framework/   (Научная рамка и языковая политика)
    │   ├── journal/     (Исследовательский журнал)
    │   ├── reports/     (Доклады по итогам циклов)
    │   ├── adr/         (Архитектурные и методологические решения)
    │   ├── hypotheses/  (Реестр гипотез)
    │   └── notes/       (Модель угроз, матрицы сравнения)
    ├── meta/            (Статус, чеклисты, дорожная карта, предположения)
    └── archive/         (Архив опровергнутых гипотез и устаревших артефактов)

## Правила работы с репозиторием

1. Репозиторий является официальным исследовательским артефактом.
2. История переписки участников не заменяет документы в репозитории.
3. Завершенные смысловые этапы фиксируются Git Tag.
4. Изменения утвержденных результатов вносятся только через новые исследовательские циклы.
