# LER — Реестр исходных предположений (Assumptions Register)

## Назначение документа
Фиксация явных и скрытых предположений, на которых базируется текущая постановка исследовательской задачи. 
Любое предположение, обнаруженное в ходе работы, должно быть вынесено сюда для последующей проверки или фальсификации.

## Статус документа
Черновик / В процессе наполнения

---

## 1. Предположения о природе исследуемого феномена
[Заполняется Мастером / Проектным архитектором]

* Пример: "Инженерное рассуждение обладает скрытой структурой, которая может быть выявлена."
* Статус: [Не проверено / Опровергнуто / Подтверждено]

## 2. Предположения о методе исследования
[Заполняется Мастером / Проектным архитектором]

* Пример: "Существующих научных рамок достаточно для контроля эпистемической чистоты исследования."
* Статус: [Не проверено / Опровергнуто / Подтверждено]

## 3. Предположения об источниках и данных
[Заполняется Мастером / Проектным архитектором]

* Пример: "Исторические документы и отчеты об авариях адекватно отражают процесс принятия решений, а не только его итог."
* Статус: [Не проверено / Опровергнуто / Подтверждено]

## 4. Скрытые предположения (обнаруженные в ходе аудита)
[Заполняется по мере выявления]

---

## Правила работы с реестром
1. Предположение не является фактом.
2. Каждое предположение должно иметь критерий фальсификации (как мы поймем, что оно ошибочно).
3. При переходе на новый этап реестр пересматривается.
