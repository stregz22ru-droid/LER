- Программа провела семь циклов исследования
- Собран достаточный объём данных для классификации утверждений
- Отсутствие данных о новых типах доказательства является результатом исследования, а не недостатком

**Почему «ЗАКРЫТИЕ ПРОГРАММЫ — УСЛОВНОЕ ВОЗОБНОВЛЕНИЕ ВОЗМОЖНО»:**
- Программа достигла эпистемической границы текущей ветви
- Новый тип различающего доказательства не определён
- Простое расширение корпуса не было признано достаточным основанием для продолжения
- Однако возобновление теоретически возможно при появлении нового типа доказательства

## РАЗДЕЛ 15: УСЛОВИЯ ВОЗОБНОВЛЕНИЯ

### 15.1. Условия, при которых возобновление стало бы научно оправданным

Для научно оправданного возобновления программы потребовалось бы **одновременное** выполнение следующих условий:

1. **Новый исследовательский вопрос**
   - Не повторение вопросов циклов 001-007
   - Не простое расширение корпуса
   - Вопрос, возникающий из установленного результата

2. **Новый класс доказательств**
   - Не «больше данных», не «больше теорий», не «больше источников»
   - Конкретная процедура, позволяющая различить то, что не было различено в циклах 001-007

3. **Новая процедура различения**
   - Позволяющая независимо варьировать факторы (задача, метод, традиция)
   - Или позволяющая различить неразличимые альтернативы (природа вербальных отчётов, природа слепоты к выбору, существование имплицитных аттитюдов)

4. **Независимый источник данных**
   - Не повторение корпусов циклов 001-007
   - Данные, которые не были доступны в ходе семи циклов

5. **Конкретная нерешённая проблема**
   - Не «мы не знаем всего»
   - Конкретное противоречие или разрыв, выявленный в ходе семи циклов

### 15.2. Что НЕ является основанием для возобновления

- «Найти ещё литературу» — не основание
- «Расширить корпус» — не основание (само по себе расширение без нового типа доказательства не было признано достаточным основанием)
- «Продолжить, потому что осталось неизвестное» — не основание
- «Продолжить, потому что интересно» — не основание

### 16.1. Решение

Межаудиторский брифинг **не проводится автоматически**.

### 16.2. Условия, при которых он понадобится

Брифинг потребуется, если:
1. Независимый аудитор обнаружит существенное расхождение с данным отчётом

4. Появится новый класс доказательства, требующий пересмотра статуса программы
5. Возникнет обоснованное предложение возобновить программу
