# LER Research Language Policy v0.1

## Статус документа
Черновик / В процессе наполнения (Этап 1)

## Назначение документа
Установление правил научного языка и терминологической дисциплины для предотвращения преждевременного моделирования, подмены наблюдений интерпретациями и скрытого введения сущностей.

---

## 1. Базовые принципы языка исследования
[Наполняется Мастером / Проектным архитектором]
- Приоритет точности и воспроизводимости над эстетикой или завершенностью объяснения.
- Запрет на апелляцию к авторитету (включая Мастера и Архитекторов) как к источнику научной истинности.
- Принцип эпистемической задержки: сохранение явления в статусе наблюдения до проверки объяснения.

## 2. Разделение эпистемических состояний
[Наполняется Мастером / Проектным архитектором]
- **Наблюдение (Observation):** Только зарегистрированные данные и факты.
- **Интерпретация (Interpretation):** Предположение, построенное на основе наблюдения.
- **Гипотеза (Hypothesis):** Формулировка, требующая целенаправленной проверки.
- **Вывод (Conclusion):** Утверждение, выдержавшее процедуру проверки и фальсификации.
*Жесткое правило: Запрещено использовать язык вывода и факта для описания интерпретации.*

## 3. Запрещенная терминология (Преждевременное моделирование)
[Наполняется Мастером / Проектным архитектором]
Списел понятий, которые запрещено использовать до получения явных исследовательских оснований:
- "сущность", "структура", "процесс", "механизм", "система", "архитектура", "синтаксис", "онтология", "язык".
*Разрешенная альтернатива:* Использование нейтральных описательных конструкций ("наблюдаемое явление", "повторяющийся паттерн", "регистрируемый эффект", "случай").

## 4. Фиксация неопределенности и ограничений
[Наполняется Мастером / Проектным архитектором]
Обязательные языковые конструкции для случаев недостатка данных или отсутствия результата:
- "Недостаточно данных для вывода".
- "В пределах проведенного исследования оснований для существования этого не обнаружено" (вместо "Этого не существует").
- "Альтернативные объяснения не найдены в пределах проведенного поиска" (вместо "Альтернатив не существует").

## 5. Работа с источниками и цитирование
[Наполняется Мастером / Проектным архитектором]
- Обязательное указание источника для каждого существенного утверждения.
- Строгое разделение содержания первичного источника и собственной интерпретации исполнителя.
- Запрет на выдачу вторичного описания за первичный факт.

## 6. Пересмотр и коррекция языка
[Наполняется Мастером / Проектным архитектором]
- Правила изменения значений терминов по мере поступления новых данных.
- Запрет на искусственное согласование (подгонку) противоречащих друг другу результатов.
- Фиксация истории изменения смыслов (без переписывания истории задним числом).
