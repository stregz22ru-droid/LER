# LER — Ретроспективный эпистемический анализ Циклов 001-006 (Цикл 007)

## Статус документа
Основной аналитический документ Цикла №007. Содержит ретроспективную оценку накопленного результата Циклов №001-006 с классификацией эпистемического статуса каждого существенного утверждения.

**Границы:** Анализ основан исключительно на артефактах завершённых циклов. Корпус не расширяется. Новые исследования не проводятся.

**Запрет:** Синтез, создание модели, объявление характеристик фундаментальными, искусственное продолжение.

**Языковой стандарт:** Русскоязычные термины при первом упоминании сопровождаются англоязычным оригиналом в скобках. Английский оригинал не является доказательством устоявшегося значения термина.

## 1. РЕКОНСТРУКЦИЯ ТРАЕКТОРИИ ЦИКЛОВ 001-006

### Цикл 001: Формирование корпуса

**Исследовательский вопрос:** Какие подходы к исследованию инженерного рассуждения существуют и каковы их границы?

**Первоначальное наблюдение:** Существует минимум 8 различных подходов (4 западных, 4 отечественных), исследующих разные аспекты рассуждения.

**Конкурирующая интерпретация:** Различия между подходами могут быть следствием разных объектов, задач, уровней описания или терминологии.
